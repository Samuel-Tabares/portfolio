Sobre Mí

Construyo backends y aplicaciones web a medida con Python/Django, React y APIs de IA. Mi sweet spot son los proyectos que necesitan arquitectura desde cero o integraciones complejas — no plantillas, ni código que se rompe en seis meses.

He desarrollado un backend de gestión veterinaria con 8 módulos y 20+ endpoints, una arquitectura de microservicios que conecta Java, Python y Node.js, y una plataforma de importación con sistema de calificación. Cada uno con problema real, no demo.

Trabajo de forma directa y enfocada: pocas reuniones, mucho código, decisiones documentadas. Si necesitás algo construido bien la primera vez —no rehacerlo en tres meses—, esa es la idea.
